<h3 id="cn-v0.3.0">适配 DSH 0.1.7-rc.1</h3>

- 修复在 DSH `0.1.7-rc.1` 上费用胶囊与面板**整体消失**：该版本把官方图标从「尺寸命名」改成了「字重命名」（`IconDatabaseOutline16` → `IconDatabaseOutlineRegular` / `Medium`），插件解构出 `undefined` 后交给 React 渲染会抛「Element type is invalid」，直接炸掉整个 occupant。现在按名字可用性取用，两套命名都能用，都取不到时降级为不画图标，而不是连累整枚胶囊。
- 修复面板变成一层能看穿页面的玻璃：`--dsw-specific-menu` 在 0.1.7-alpha.1 起从不透明变成半透明，官方契约要求绘制该底色的高层级表面**同时**应用 `backdrop-filter: var(--dsw-menu-backdrop-filter)`。面板按这条配对；吸顶的保存条嵌在面板内部、嵌套滤镜不会生效，改用不透明层级底色。
- 修复选中页签底色、徽章底色、警告面与分隔符颜色静默丢失：此前引用了四个 DSH 从未定义过的设计 token（`--dsw-alias-fill-l1` / `-l2`、`--dsw-alias-separator-primary`，以及 `--dsw-alias-state-warning-primary` 这个 `state-warn-primary` 的笔误）。引用不存在的自定义属性会让**整条声明**在计算值阶段失效，因此这些样式一直没有生效。

<h3 id="cn-v0.3.0-pill">胶囊细节</h3>

- 各段间距收紧：分隔符此前是胶囊的直接子项，`gap` 在它两侧各多付一次，一个点从约 15px 撑到约 27px。现在与官方 `StatsPills` 同结构，收进同一个 flex 分组。
- 分隔符不再比官方更淡，并恢复跟随悬停变亮。

<h3 id="cn-v0.3.0-compat">兼容性</h3>

- 兼容 `0.1.5-rc.1` 起的所有版本。核对覆盖 `0.1.5-rc.1` ~ `0.1.7-rc.1` 共 8 个 tag：插件依赖的 slot 契约、`useProjection` 标准座位、`locale` 服务、官方组件导出与设计 token 全程稳定。仅有的两条版本边界——`0.1.6-alpha.2` 的 dock 转横向 flex、`0.1.7-alpha.1` 的图标改名与菜单材质变半透明——都做成了按可用性回退或按规范降级，**不依赖 DSH 版本号**（浏览器侧拿不到）。矩阵见 `docs/dsh-integration.md`。

<h3 id="cn-v0.3.0-docs">文档</h3>

- README 收敛为纯用户手册（223 → 180 行），实现细节移入 `docs/`：配置参考、内部机制、DSH 集成约束、开发指南。两份 README 仍逐行对齐，新增文档为双语同文件。

<h3 id="en-v0.3.0">DSH 0.1.7-rc.1 support</h3>

- Fixed the cost pill and its panel **vanishing entirely** on DSH `0.1.7-rc.1`: that release renamed the built-in icons from size-based to weight-based names (`IconDatabaseOutline16` → `IconDatabaseOutlineRegular` / `Medium`), so the plugin destructured `undefined` and handed it to React, which threw "Element type is invalid" and killed the whole occupant. Icons are now resolved by which name exists; both namings work, and the plugin degrades to drawing no icon rather than losing the pill.
- Fixed the panel becoming a pane you can see the page through: from 0.1.7-alpha.1 `--dsw-specific-menu` changed from opaque to translucent, and the built-in contract requires an elevated surface painting that fill to **also** apply `backdrop-filter: var(--dsw-menu-backdrop-filter)`. The panel follows that pairing; the sticky save bar sits inside the panel where a nested filter cannot reach, so it uses an opaque layer fill instead.
- Fixed silently dropped colours on the selected tab, badges, warning surfaces and separators: the plugin named four design tokens DSH never defines (`--dsw-alias-fill-l1` / `-l2`, `--dsw-alias-separator-primary`, and `--dsw-alias-state-warning-primary`, a typo for `state-warn-primary`). Referencing an undefined custom property invalidates the **whole declaration** at computed-value time, so those styles had never applied.

<h3 id="en-v0.3.0-pill">Pill details</h3>

- Tightened the gaps between parts: the separator used to be a direct child of the pill, paying the `gap` twice more and stretching one dot from roughly 15px to roughly 27px. It now shares the built-in `StatsPills` structure, grouped into a single flex item.
- The separator is no longer fainter than the built-in one, and follows the hover colour again.

<h3 id="en-v0.3.0-compat">Compatibility</h3>

- Compatible with every release from `0.1.5-rc.1` onwards. The check covered the eight tags from `0.1.5-rc.1` to `0.1.7-rc.1`: the slot contract, the `useProjection` standard seat, the `locale` service, the built-in component exports and the design tokens all held throughout. The only two version boundaries — the dock becoming a flex row in `0.1.6-alpha.2`, and the icon rename plus translucent menu material in `0.1.7-alpha.1` — are handled by availability fallbacks or spec-defined degradation, with **no dependency on the DSH version** (which the browser side cannot read). The matrix is in `docs/dsh-integration.md`.

<h3 id="en-v0.3.0-docs">Documentation</h3>

- The README is now a pure user manual (223 → 180 lines), with implementation details moved into `docs/`: configuration reference, internals, DSH integration constraints, development guide. Both READMEs remain line-for-line aligned, and the new documents are bilingual in a single file.
