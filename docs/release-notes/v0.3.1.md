<h3 id="cn-v0.3.1">问题修复</h3>

- 修复费用面板里的输入框与下拉框与 DSH 其余控件风格不一致：它们此前是 `1px` 的 `--dsw-alias-border-l2` 描边、7px 圆角、`bg-overlay` 底色，聚焦时只把描边从 l2 换成 l1——那是一圈「稍深一点的灰边」，比别处重，对焦时又几乎看不到反应。
- 现在统一到官方 `ConfigField` / `settings-form` 的控件配方：**0.5px 发丝描边**（`--dsw-alias-border-l4`）、**8px 圆角**、**层级底色**（`--dsw-alias-bg-layer-3`），聚焦换成**品牌色**描边（`--dsw-alias-brand-primary`）。覆盖输入框、下拉框、供应商 / 模型组合框、高峰时段时钟框、规则名输入框与星期按钮；星期按钮与组合框箭头另外补上官方的 `:focus-visible` 轮廓。
- 非法值改用官方的 `aria-invalid='true'` 着色（此前是自造的 data 属性），控件高度统一到 28px——官方紧凑档，与按钮同高。

<h3 id="cn-v0.3.1-docs">文档</h3>

- README 的安装一节补上 **DSH `0.1.6-alpha.2` 起的插件管理器路径**：侧栏「插件」→「添加插件」，可填 npm 包名、GitHub 简写、仓库地址或本地路径，装完点「立即启用」。同时说清两件事：**包名**走所选注册表（npmmirror 可用），而**仓库地址**仍走 GitHub 直连，镜像不代理仓库本身；安装成功不代表模块一定能激活。
- 命令行一节补上 `dsh plugin --profile web add "@lantiosity/dsh-token-fee"`。

<h3 id="en-v0.3.1">Bug fixes</h3>

- Fixed the cost panel's inputs and dropdowns not matching the rest of DSH: they used a `1px` `--dsw-alias-border-l2` stroke, a 7px radius and the `bg-overlay` fill, and focused by moving the stroke from l2 to l1 — a slightly darker grey ring, heavier than everywhere else and with almost no visible focus response.
- They now follow the built-in `ConfigField` / `settings-form` control recipe: a **0.5px hairline** (`--dsw-alias-border-l4`), an **8px radius**, the **layer fill** (`--dsw-alias-bg-layer-3`), and a **brand-coloured** focus stroke (`--dsw-alias-brand-primary`). This covers inputs, selects, the provider/model combobox, the peak-window clock fields, the rule-name field and the weekday buttons; the weekday buttons and the combobox arrow also gained the built-in `:focus-visible` outline.
- Invalid values now use the built-in `aria-invalid='true'` colouring (previously a hand-rolled data attribute), and control heights are unified at 28px — the built-in compact step, level with buttons.

<h3 id="en-v0.3.1-docs">Documentation</h3>

- The README's install section now documents the **plugin manager path, available since DSH `0.1.6-alpha.2`**: sidebar → Plugins → Add plugin, taking an npm package name, a GitHub shorthand, a repository URL or a local path, with **Enable now** when it finishes. Two things are spelled out: a **package name** resolves through the selected registry (so npmmirror works), while a **repository URL** still goes straight to GitHub because a mirror does not proxy the repository itself; and a successful installation does not certify that the module can activate.
- The command-line section gained `dsh plugin --profile web add "@lantiosity/dsh-token-fee"`.
